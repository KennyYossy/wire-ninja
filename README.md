# Wire Ninja

ネオンの夜の街（と夕暮れの港）を、ワイヤーでビルからビルへ飛び移る3Dスイングゲーム（スマホ向け試作）。

`index.html` 1枚で動きます（Three.js r128 を cdnjs から読み込み）。ブラウザで開くだけで遊べます。

## 操作
- 画面の左半分 / 右半分を押す: 左 / 右のビルにワイヤー（狙いは自動、照準が出る）
- 押している間ぶら下がり、離すと外れる
- 刺したまま指を上にスライド: 巻き取り（半径が短くなり振りが速くなる）
- 画面中央下のジェット: 丸いパッドの押した側（上下左右）に急加速（10秒に1回、白い噴射）
- 右上「調整」: 重力・加速・射程・最低スピード・曲がる強さ（開いている間は一時停止）
- PC: ←/→ キー、またはマウス。ジェットは W/S/Q/E（上/下/左/右）

## スコア
- 移動距離（どの方向でも）1m = 10pt
- 青アイテム 1000pt。金アイテムは点数なしで、取るたびに回転ジャンプの回転スピードが1.2倍ずつ上がる、加速力も1.1倍ずつ上がる（そのゲーム中ずっと）
- 銀アイテム: 取るとジェットが即回復し、ジェットの待ち時間が10%ずつ短くなる（金の半分くらい出る）
- 地面すれすれ（高さ4m未満まで下がって落ちずに通過）1500pt。一度8mより上に戻るとまた狙える
- ビルすれすれ 200pt、ビルの間を両側すれすれ（Wスレスレ）1000pt、屋上に着地 100pt
- 回転大ジャンプ: 完全に回った回数に応じて 100 → 200 → 300 → 500 → 800 → 1300 …（フィボナッチ風、上限なし、滞空1.5秒以上で成功）。回転数に応じて GOOD → COOL → NICE → GREAT → EXCELLENT → FANTASTIC → AMAZING → UNBELIEVABLE と演出が豪華になる
- ビルの間にたまに橋がかかっている。下をくぐると +500〜2000pt（低い橋ほど高い。色は 水色→ピンク→金 の順に高得点。橋すれすれは別にすれすれ加算）、橋の上（緑色）に着地すると +1000pt、橋の側面や底にぶつかると失敗
- 巻き取りはワイヤーが長いほど速い（30mで標準、長いと最大2.5倍）
- ワイヤーは刺してから5秒で切れる（最後の1.5秒は赤く点滅）。切れたら指を一度離さないと次のワイヤーは出ない
- バックフリップ: 進む向きが3秒以内に180°近く逆向きになったら +1000pt（巻き取りすぎてUターンしたときなど）
- ドパガキモード: タイトルから選べる、アイテムの出現が5倍のモード。ベストスコアは通常モードと別に記録
- モード解放: ドパガキは通常を10回、超ドパガキはドパガキを10回、極ドパガキは超ドパガキを10回遊ぶと解放（ゲームオーバーまで遊んだ回数で数える）。解放前のボタンは光らず「？？？」表示
- 超ドパガキモード: アイテムの出現が10倍。ベストスコアは別に記録
- 極ドパガキモード: 金アイテム20倍、青・銀は10倍。ベストスコアは別に記録
- ビルの屋上にも30%の確率でアイテムが置いてある（着地して取れる）
- タイトル画面: スタート／ドパガキ／超ドパガキ／極ドパガキ／チュートリアル／遊び方・得点（操作と得点一覧）
- チュートリアル: タイトルの「チュートリアル」から。左右ワイヤー → 離して飛ぶ → 300m進む → 巻き取り → ジェット → すれすれ → 青アイテム → 金アイテム → 銀アイテム → 橋くぐり → 屋上着地 → 回転ジャンプ → バックフリップ → コンボ の15ステップ（ジェットと青アイテム以降は各2回でクリア、練習中のジェットは3秒に1回）。クリアするたびにスタート地点に戻り、タップで次のお題が始まる。ジェット・巻き取り・アイテム・コンボなどは、その章になるまで表示も動作もしない。ぶつかってもその場で復活、各ステップはスキップ可
- 終了画面: スコアのカウントアップ、NEW RECORD 表示、得点の内訳、最大コンボなどの記録、「もう一度」「タイトルへ」ボタン

## コンボ
- ボーナスや演出が出るたびにコンボが1つ増える（左上に表示、ゲージが切れるとリセット）
- 初期は3秒で切れ、最大10コンボ。青アイテムを取るたびに最大+5、時間+1秒
- ボーナス得点には、そのときのコンボ数×5%が上乗せされる
- 言語: タイトル右上で日本語／英語を切替（最初はブラウザの言語、選んだ言語は保存）
- シェア: 結果画面の「結果をシェア・友達に挑戦」から X／共有／コピー（claude.ai 上ではブラウザの制限で動かないことがあり、その場合は文を長押しでコピー）。文面に挑戦コード（例 D-12345、N=通常 D=ドパガキ S=超 K=極）とリンクが入る
- 挑戦: タイトルの「挑戦コードを入力」か `?challenge=12345&mode=dopa` 付きのURLで挑戦状を受けると、プレイ中に目標スコア、結果画面に勝ち負けが出る（サーバー不要）。未解放モードの挑戦状を受けるとそのモードがすぐ解放される

## ステージ（v1.2〜）
- タイトルのメニュー上で「夜の街」「夕暮れの港」を切替（選んだステージは保存、ベスト記録はステージごと）
- 夕暮れの港: どのモードでも合計10回遊ぶと解放（それまでは「？？？」）。オレンジの空・海・倉庫・コンテナ・クレーン・船
- クレーン: 腕がゆっくり回る。先端の赤いランプにワイヤーが刺さり、刺したまま一緒に動く。マストにぶつかると失敗
- 船: 低く進む。緑の甲板（と船橋の屋根）に着地すると +500pt で、ゆっくり歩きながら休める。端まで来ると自動ジャンプ。船の側面にぶつかる・海に落ちると失敗
- 港には橋はない。チュートリアルは常に夜の街
- 挑戦コード: 港は先頭に H（例 HN-12345、HD-…）。URLは `&stage=harbor`。港の挑戦状を受けると港も解放される
