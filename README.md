# Wire Courier

ネオンの夜の街を、ワイヤーでビルからビルへ飛び移る配達員の3Dスイングゲーム（スマホ向け試作）。

`index.html` 1枚で動きます（Three.js r128 を cdnjs から読み込み）。ブラウザで開くだけで遊べます。

## 操作
- 画面の左半分 / 右半分を押す: 左 / 右のビルにワイヤー（狙いは自動、照準が出る）
- 押している間ぶら下がり、離すと外れる
- 刺したまま指を上にスライド: 巻き取り（半径が短くなり振りが速くなる）
- 右上「調整」: 重力・加速・射程・最低スピード・曲がる強さ（開いている間は一時停止）
- PC: ←/→ キー、またはマウス

## スコア
- 移動距離（どの方向でも）1m = 10pt
- 空中アイテム 500pt / 金 1000pt
- ビルすれすれ 200pt、屋上に着地 100pt
- 回転大ジャンプ: 完全に回った1回転ごとに200pt（最大800pt、滞空1.5秒以上で成功）
